Route debug tools

Small browser-only tools for debugging routing engine output.

  • OSRM step debugger Paste an OSRM-format response and inspect its legs, steps and turn weights on a map.
  • Trace attributes visualizer Paste a Valhalla trace_attributes response and color its edges and nodes by any attribute.
  • Attributes controller builder Pick Valhalla attributes from a list and get the include or exclude filter as JSON.
